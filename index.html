Privacy Policy

This policy explains how HGB Systems collects, uses, stores and protects information when you interact with its Discord application and associated services.

Effective date: November 6, 2026

1. Information We Collect

We collect data necessary to provide remote server management, moderation, session tracking and economy features:

  • Discord User Information: User IDs, usernames and server (guild) IDs.
  • Roblox Data: Roblox usernames, Roblox User IDs and verification link records (when linked via account verification).
  • Server Logs & Moderation Data: Warning records, ban/kick logs, voided log history, action timestamps, and session logs (join/leave, kill logs, command executions and vehicle spawns).
  • In-Game Activity & Economy: Discord economy data derived from ERLC session participation and server management activities.

2. How We Use Your Information

We process collected data strictly to operate and improve HGB Systems:

  • To log, moderate and track server and player activities within ERLC servers.
  • To execute automated moderation actions (e.g., auto-kicks based on warning thresholds).
  • To manage server sessions, department systems, CAD integration and economy features.
  • To maintain fuzzy-search lookups for Roblox usernames and IDs across moderation records.

3. Data Storage and Security

  • Data Integrity: We store moderation logs securely and maintain a "Voided" status mechanism rather than permanent deletion to preserve server audit trails.
  • Access Control: Log access is restricted to authorized server administrators and moderators based on configured permissions.
  • Third-Party Services: We do not sell, rent or trade your personal information to third parties.

4. Data Retention and Deletion

  • Server administrators can manage, void or clear logs within the scope of their server configuration.
  • To request removal of linked account data or moderation history, contact the support team through the official HGB Systems Discord portal.

5. Changes to This Policy

We may update this Privacy Policy periodically to reflect new features (such as CAD systems or economy updates). Continued use of HGB Systems constitutes acceptance of the revised policy.

6. Contact Us

If you have questions or concerns about this Privacy Policy, reach out via the HGB Systems Discord/community support portal.
